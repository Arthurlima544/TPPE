# Técnicas de Programação em Plataformas Emergentes (TPPE)

Este repositório serve como um storage dos exercícios práticos desenvolvidos durante a disciplina de "Técnicas de Programação em Plataformas Emergentes". O projeto foi construído em **Java** com foco na aplicação de boas práticas de desenvolvimento, padrões de projeto e técnicas de programação defensiva.

## Objetivo

O objetivo principal deste repositório é documentar e demonstrar a aplicação prática dos seguintes conceitos avançados de engenharia de software:

-   **Programação Defensiva:** Uso de assertivas e programação por contrato para construir software mais robusto.
-   **Qualidade e Manutenibilidade:** Aplicação de técnicas de refatoração, documentação de código e boas práticas de projeto.
-   **Testes e Depuração:** Criação de testes unitários com JUnit para garantir a correção do código e estratégias para tratamento de erros e depuração.
-   **Padrões de Projeto (Design Patterns):** Implementação de padrões de software para solucionar problemas comuns de design, como visto nas pastas `pluggable_selector` e `structural_patterns`.

##  Estrutura do Repositório

O código está organizado em pastas, cada uma representando um conceito, padrão ou exercício específico abordado em aula. Alguns exemplos notáveis incluem:

-   `junit/`: Exemplos e configurações para a criação de testes unitários com JUnit.
-   `structural_patterns/`: Implementação do padrão de projeto estrutural *Composite*.
-   `pluggable_selector/`: Estudo e implementação do padrão *Pluggable Selector*.
-   `palindromo/`: Exercício prático para validação de palíndromos, com foco em testes de unidade.
-   `controle_de_estoque/`: Um pequeno sistema para demonstrar vários dos conceitos aprendidos.

## Tecnologias Utilizadas

-   **Linguagem:** Java
-   **Testes:** JUnit

##  Como Executar

Por se tratar de um conjunto de exercícios independentes, não há um ponto de entrada único para o projeto. Para explorar o código:

1.  Clone o repositório:
    ```bash
    git clone https://github.com/Arthurlima544/Emerging-platforms-exercises.git
    ```
2.  Abra o projeto em sua IDE Java favorita (Eclipse, IntelliJ IDEA, etc.).
3.  Navegue até a pasta de interesse e execute a classe principal (`main`) ou a suíte de testes correspondente.
